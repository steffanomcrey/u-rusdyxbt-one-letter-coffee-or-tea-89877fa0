One letter, A for coffee. A deterministic, standard-library-only Python program that writes exactly the single letter "A" (coffee) to /output/entry.txt, with no newline and nothing else. Coffee wins the judge's criteria in order: it is the more vivid drink (dark, bitter, hot, a morning jolt) and the funnier one (the before-coffee ritual joke), while tea's calm-truth case only wins the last-weighted criterion.

## Run it

```sh
python3 main.py
```
